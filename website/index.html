Privacy notice

Before any student records

CLEAR keeps a first name, a feeling, the choice a student tapped, the time, and the teacher’s yes or no. It does not ask for an address, phone number, photo, or student ID. The week stays in this browser. It is not sent to a company server.

These notes are school records. FERPA expects the school to keep them for the classroom and to let a parent look at a child’s records and ask for a correction or deletion. COPPA’s school rule fits this page: it is used for the class, not as a public site for children, and a parent can refuse by asking the teacher not to keep that child’s panel or this browser’s copy.

  • The teacher device asks for a class PIN, then a teacher code, before it shows messages or turns on the USB drive.
  • CLEAR.CSV from the updated teacher device is locked with the class PIN. The website asks for both codes before it opens a week.
  • A student panel must use that class PIN. The teacher then allows that panel. Other panels stay on a waiting list, and their messages are not saved.
  • Names and messages on this page hide after 10 seconds with no mouse or keyboard activity. The graphs that do not name a student stay up.
  • Student panel settings go from this browser straight to that panel over USB or Bluetooth. They are not sent to a server. The settings password is not saved here.
  • Removing a week, or choosing “Delete saved weeks,” takes the copy out of this browser. Deleting CLEAR.CSV on the teacher drive clears that device’s week.

Use the same four-digit class PIN and teacher code you set on the teacher device. The first visit on this browser saves a check for those codes. It does not save the codes themselves.

Add a week from the teacher device

Sample weeks are already on this page, so the graphs can be shown before a device is plugged in. When you have a real week, choose CLEAR.CSV. A file from the updated teacher device is locked with the class PIN. It is added beside the samples, and it stays in this browser in locked form.
